# 📋 TaskTracker – Desktop App for Managing Tasks and Employees

TaskTracker is a Java-based desktop application designed for streamlined task and workforce management within a company. It features a **Swing GUI**, **multi-threaded socket server**, **MySQL database**, and a clear separation of responsibilities using **MVC architecture**.

---

## ✨ Features

- 🔐 **Login system** with role-based access (Manager or Employee)
- 👤 **Employee management** (add, update, delete, view)
- 📂 **Job/project tracking** (create, assign, manage)
- ✅ **Task assignment & status tracking**
- 🔍 **Search functionality** across all entities
- 🧠 **Socket communication** between client and server
- 🎯 Clean and role-specific user interfaces and navigation 
- 💾 Data persistence with **MySQL** backend

---

## 💡 Technologies Used

- **Java SE 17**
- **Swing** (for the graphical interface)
- **MySQL** (hosted locally via XAMPP)
- **SQLyog** (used to manage the database)
- **JDBC** (for database access)
- **Socket programming** (multi-threaded communication between client and server)
- **MVC Pattern**
